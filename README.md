# Click Before Frames

A Geode mod for Geometry Dash 2.2081 (Geode 5.11.2). It predicts your click with a hidden ghost player and, when the ghost would die, delays the input by a few physics ticks so it still saves you.

- Platforms: Windows, macOS, Android (32 and 64 bit), iOS
- Mod id: `pulse.input-buffer`
- Full description and controls: [about.md](about.md)
- How to build: [BUILDING.md](BUILDING.md)
- Changes: [changelog.md](changelog.md)

## Install

Download the `.geode` package from the GitHub Actions run (artifact **Build Output**) or build it yourself, then put it in the game's `geode/mods` folder. On Android the folder is
`/storage/emulated/0/Android/media/com.geode.launcher/game/geode/mods/`.

## Fair play

Auto-click, auto-release and a physics TPS other than 240 are not legit for records. Check the rules of the list or leaderboard you play on.
